MSc Dissertation

AI-Powered Android Malware Detection System: Balancing Detection Performance and Computational Efficiency Using Machine Learning

Supervisor: Dr. Mark Jacobi Institution: Sheffield Hallam University

Trained and evaluated machine learning classifiers on a curated dataset of 16,453 Android application samples with 810 extracted features, to identify models that are Pareto-optimal across detection performance and computational efficiency. Linear SVM and Logistic Regression emerged as the strongest trade-off points, with the Linear SVM achieving high detection accuracy at a fraction of the inference cost — making it suitable for on-device deployment. The findings are demonstrated in a companion Android application built in Kotlin and Jetpack Compose.

F1-score: 99.51% Inference: 0.0068ms Model size: 6.87KB Pareto-optimal: Linear SVM, Logistic Regression
